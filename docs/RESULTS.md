แบ่งข้อมูลเป็น **ช่วงเรียนรู้ (in-sample)** และ **ช่วงทดสอบที่บอทไม่เคยเห็น (out-of-sample)**

## learn-exits (หา TP/SL จากสถิติ)
ทุก setup **ถูกปฏิเสธ** โดยระบบกัน overfit — คู่ SL/TP ที่ดีที่สุดในช่วงเรียนรู้ ใช้กับช่วงทดสอบแล้วแย่กว่าการออกแบบเดิม
→ บอทยังคงใช้ Learning mode ต่อ (ถูกต้องตามที่ออกแบบ: ไม่ยอมใช้ TP/SL ที่ไม่ผ่านการทดสอบ)

## ข้อสรุป
1. **กฎปัจจุบันยังไม่มี edge ที่เชื่อถือได้หลังหักค่าธรรมเนียม** — ห้ามใช้เงินจริง
2. ระบบป้องกันทำงานจริง: kill-switch หยุดที่ DD 20% บนทองคำ, ด่านจิตวิทยาบล็อก tilt/revenge, learn-exits ปฏิเสธผลที่ overfit
3. สัญญาณที่น่าสนใจ (ต้องทดสอบเพิ่ม ยังสรุปไม่ได้): `ICT_OTE_KILLZONE` และ `PA_SR_CANDLE` เป็นบวกทั้งสองช่วงบน BTC
4. ปัญหาหลัก: stop แคบ (ค่าธรรมเนียมกินไป ~0.13R ต่อเทรด) และทองคำ 1h โดน stop ตั้งแต่แท่งแรก 25%

## ขั้นถัดไป
- ทดสอบโหมด `--ai` (Claude ตัดสินใจ) บนช่วงทดสอบเดียวกัน แล้วเทียบกับกฎล้วน — ต้องมี ANTHROPIC_API_KEY
- ปรับกฎ: stop กว้างขึ้น/คัดเฉพาะ setup ที่เป็นบวก แล้วทดสอบซ้ำบนช่วง out-of-sample **ใหม่** (ห้ามปรับจนพอดีกับช่วงทดสอบเดิม)
- Testnet ระยะยาวทำได้เลยเพื่อทดสอบระบบส่งออเดอร์ (ไม่ใช่เพื่อหากำไร) — ดู `deploy/`

- เกณฑ์: exp > 0 บน **ทั้งสอง** ชุด และ DD < 20%
