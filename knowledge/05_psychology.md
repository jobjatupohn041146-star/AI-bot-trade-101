# จิตวิทยาการเทรด (Trading Psychology)

## ศัตรู 5 ตัวของเทรดเดอร์
| อารมณ์ | อาการ | ระบบป้องกันของบอท |
|---|---|---|
| FOMO (กลัวตกรถ) | ไล่ราคาที่วิ่งไปไกลแล้ว | บล็อกถ้าราคาห่าง EMA20 > 3 ATR หรือหลังแท่งยักษ์ |
| Revenge Trading (เอาคืน) | รีบเข้าใหม่ทันทีหลังขาดทุน | Cooldown หลังแพ้ + ห้ามเพิ่ม size หลังแพ้ |
| Overtrading | เทรดถี่เกินไป | จำกัดจำนวนเทรดต่อวัน |
| Tilt (เสียศูนย์) | แพ้ติดกันแล้วตัดสินใจแย่ลง | แพ้ติดกัน N ครั้ง → หยุดพัก |
| Overconfidence | ชนะติดกันแล้วเพิ่มความเสี่ยง | ห้ามเพิ่ม risk % จากการชนะติดกัน |

## หลักคิด
- คิดเป็น "ความน่าจะเป็น" ผลลัพธ์ของเทรดเดียวไม่มีความหมาย ดูผลรวม 100 เทรด
- ยอมรับความเสี่ยงก่อนเข้า: รู้ว่าจะเสียเท่าไรก่อนกดเสมอ
- ไม่มี setup = ไม่เทรด ("No trade" ก็คือ position หนึ่ง)
- ทำตามแผน 100% แม้จะแพ้ — การทำตามแผนสำคัญกว่าผลลัพธ์รายเทรด
- จดบันทึกทุกเทรด (journal) เพื่อเรียนรู้จากสถิติ ไม่ใช่จากความรู้สึก

## กฎสำคัญ (Key Rules)
- แพ้ติดกัน 3 ครั้ง → หยุดเทรดชั่วคราว (cooldown)
- ขาดทุนถึงลิมิตรายวัน → หยุดทั้งวัน
- หลังแพ้ต้องรอ cooldown ก่อนเข้าใหม่ และห้ามเพิ่ม size
- ความมั่นใจของ setup ต่ำกว่าเกณฑ์ → ไม่เทรด
- ห้ามไล่ราคา (FOMO) ห้ามเอาคืน (Revenge)
